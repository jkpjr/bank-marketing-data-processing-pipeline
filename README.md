# garment-productivity-data-processing-pipeline
Processing the Garment Worker Productivity data for data mining.

The source data is "Productivity Prediction of Garment Employees" donated to UC Irvine Machine Learning Repository on 8/2/2020 with a CC BY 4.0 License. To use and know more about the data used, please see the link: https://archive.ics.uci.edu/dataset/597/productivity+prediction+of+garment+employees

Data Reference:
Productivity Prediction of Garment Employees [Dataset]. (2020). UCI Machine Learning Repository. https://doi.org/10.24432/C51S6D.
